# HelpDesk-Python

Sistema de chamados para times de suporte, feito com Python e PostgreSQL.

> 🚧 Projeto em desenvolvimento.

## Sobre
Explique em 2 ou 3 linhas o problema que o sistema resolve: por exemplo,
organizar solicitações de suporte, atribuir a técnicos e acompanhar o status.

## Funcionalidades
- [ ] Abrir chamado (título, descrição, prioridade)
- [ ] Atribuir chamado a um técnico
- [ ] Alterar status (aberto, em andamento, fechado)
- [ ] Comentários e histórico
- [ ] Login com perfis (solicitante, técnico, admin)

## Tecnologias
- Python
- PostgreSQL
